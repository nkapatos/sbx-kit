# sbx-kit

Companion CLI for [Docker AI Sandboxes](https://docs.docker.com/ai/sandboxes/) (`sbx`).
It manages recipe catalogs and sandbox lifecycle on top of the `sbx` CLI.

Install, then:

```bash
sbx-kit setup
sbx-kit --help
```

Live reference: `sbx-kit --help` and `sbx-kit concepts`.
